Entry for make.fun's **The One-Line Laugh** (`u-ronigrv-the-one-line-laugh-7ccca46f`): one original funny line, at most 200 characters, on everyday life. This entry takes the household angle — a mum's "five minutes" before dinner, and the timer her child has learned to actually set.

## The line

> Mum said dinner would be ready in five minutes, so I set a timer for the forty-five minutes she meant.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic, no network, no model calls, no file reads outside the repo.
